# Waallpaper 0.4.0 Preview

One wallpaper, across every screen.

## Included

- Span a static wallpaper across selected macOS displays.
- Save a physical monitor layout independently of macOS display arrangement.
- Drag displays, resize corner handles, and snap edges to align the image.
- Show a temporary grid and reference lines on the actual monitors.
- Switch between Korean, English, and the system language.
- Export per-display PNGs and restore recorded previous wallpapers.
- Reuse existing MoreWallpaper settings and restore records.

## Download

`Waallpaper-0.4.0-macOS-universal.zip` contains Apple Silicon and Intel code for macOS 14 or later. Unzip it to obtain `Waallpaper.app`. `SHA256SUMS` and `RELEASE-INFO.txt` describe the package and its verification.

**This is an ad hoc signed, non-notarized preview.** It has no Developer ID signature or Apple notarization. macOS may block a downloaded copy from launching. Source builds are documented in the README.

## Verification

- 105 automated tests passed.
- The archived app launched on Apple Silicon with existing settings preserved.
- Independent manual layout and actual two-display wallpaper application were checked.
- Both binary architectures, bundled languages, strict code signature, archive contents, and checksums were verified.

Intel runtime behavior, other macOS versions, and all Spaces/lock-screen combinations remain unverified.
