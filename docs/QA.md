# Waallpaper 0.4.0 — 검증 기록

검증일: 2026-09-28. 실행 환경: Apple Silicon, macOS 27.0, 내장 Retina 화면과 외부 모니터 2대.

## 자동 테스트

`swift test`: **105개 성공, 실패 0개**.

| 영역 | 테스트 수 | 주요 검증 |
| --- | ---: | --- |
| Core | 72 | 화면 좌표·분할·방향·EXIF·출력 제한·언어·직접 조절·정렬 패턴·수동 배치·기존 저장 경로 호환 |
| Desktop | 23 | 적용·내보내기·원본 보존·권한 제한·부분 실패 복구·모니터 연결 상태 검사 |
| App | 10 | 언어와 설정 저장·이전 설정 호환·시스템/수동 배치 전환·재연결·재실행 |

테스트의 데스크탑 변경은 가짜 클라이언트를 사용합니다. 실제 OS 적용 검증은 별도로 진행했습니다.

### 수동 배치

- 캡처한 기준 좌표로 실제 배치를 저장하고, 이후 시스템 좌표나 논리 해상도가 바뀌어도 수동 위치·크기가 유지되는지 확인했습니다.
- 화면의 실제 출력 픽셀 수는 현재 모니터 정보를 사용합니다.
- 시스템 모드와 수동 모드의 보정값을 따로 보관합니다.
- 재연결, 재실행, 화면 순서 변경 후에도 모니터 식별자에 맞는 설정을 복구합니다.
- 크기 조절은 반대쪽 모서리와 화면 비율을 유지합니다.

## 실제 앱 검증

- 릴리스 ZIP에서 꺼낸 **Waallpaper.app**을 실행했습니다.
- 기존 MoreWallpaper의 이미지·확대·위치·언어·복원 기록을 읽는 것을 확인했습니다.
- macOS는 위아래 배치인 상태에서 앱의 수동 모드만 좌우 배치로 바꿨습니다.
- 시스템 모드로 전환하면 기존 배치로 돌아가고, 수동 모드로 다시 전환하면 따로 저장한 배치를 복구했습니다.
- 수동 배치로 두 화면에 적용하고 `NSWorkspace.desktopImageURL(for:)`에서 각각 생성된 PNG를 사용하는 것을 확인했습니다.
- 검증용 배치를 초기화하고 원래 설정으로 재적용했습니다. 기존 설정과 비교해 테스트 변경이 남지 않도록 정리했습니다.
- 이전 기능 검증에서 언어 즉시 전환, 드래그 이동·모서리 크기 조절·가장자리 맞춤, 실제 화면 정렬 패턴 표시·Esc 종료, PNG 내보내기, 원래 배경 복원을 확인했습니다.

## 배포 패키지

`scripts/package-release.sh`로 다음을 확인했습니다.

- `arm64`와 `x86_64`를 포함하는 Universal 실행 파일
- 유효한 앱 plist와 한국어·영어 리소스
- 임시 서명(ad hoc)의 엄격한 코드 서명 검증
- ZIP 압축 해제 후 모든 파일의 해시와 실행 권한 일치
- 압축 해제한 앱의 아키텍처·언어 리소스·서명 재검증
- ZIP과 배포 정보 파일의 SHA-256 체크섬

이 검증은 **Apple의 Developer ID 서명 또는 공증을 의미하지 않습니다.** 현재 공개 파일은 공증이 없는 프리뷰입니다.

## 확인하지 않은 범위

- Intel Mac에서의 실제 실행: x86_64 코드는 빌드·포함 확인만 했습니다.
- macOS 14–26에서의 실제 실행: 최소 배포 대상은 macOS 14지만 수동 검증은 macOS 27에서 진행했습니다.
- 다른 Spaces, 잠금 화면, 잠자기, 실제 케이블 분리 상태의 모든 조합
- 동적 배경의 재생 상태와 셔플 일정 복원
- 실물 인치 크기와 베젤에 대한 자동 측정: 사용자가 정렬 패턴을 보며 맞춥니다.

## 다시 검증하기

```sh
swift test
./scripts/package-release.sh
cd build/releases/v0.4.0
shasum -a 256 -c SHA256SUMS
```

배포 폴더가 이미 있으면 패키징 스크립트는 덮어쓰지 않고 종료합니다. 새 버전을 만들 때는 `scripts/Info.plist`의 버전을 먼저 갱신합니다.
