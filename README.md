# Waallpaper

**One wallpaper, across every screen.**

한 장의 배경화면을 여러 Mac 모니터에 이어서 표시하는 앱입니다. 모니터마다 다른 크기·해상도·배율을 보정하고, macOS 설정과 별개로 실제 책상 위 배치를 맞출 수 있습니다.

[**v0.4.0 프리뷰 다운로드**](https://github.com/s1ckdark/waallpaper/releases/tag/v0.4.0) · [검증 기록](docs/QA.md)

## 주요 기능

- **배경화면 연결:** 좌우·위아래 배치, 세로 화면과 화면 사이 간격 반영
- **독립적인 실제 배치:** 시스템 배치와 수동 배치를 따로 저장하고 전환
- **눈으로 보정:** 화면 드래그 이동, 모서리 크기 조절, 가장자리 자동 맞춤
- **정렬 패턴:** 실제 모니터에 격자와 기준선을 잠시 띄워 경계 확인
- **화면별 적용·내보내기:** 선택한 화면에 적용하거나 PNG로 저장
- **복원과 설정 저장:** 이전 배경 기록, 모니터별 보정값과 언어 유지
- **한국어 / English / 시스템 언어**

이미지와 설정은 Mac 안에서 처리합니다. 계정이나 서버 연결은 필요하지 않습니다.

## 다운로드

- macOS 14 이상
- Apple Silicon·Intel 코드를 포함한 Universal 앱
- [Waallpaper-0.4.0-macOS-universal.zip](https://github.com/s1ckdark/waallpaper/releases/download/v0.4.0/Waallpaper-0.4.0-macOS-universal.zip)

ZIP을 풀고 `Waallpaper.app`을 응용 프로그램 폴더로 옮깁니다. 릴리스에는 `SHA256SUMS`와 서명 상태를 기록한 `RELEASE-INFO.txt`도 포함합니다.

**현재는 Apple 공증이 없는 프리뷰 빌드입니다.** 임시 서명(ad hoc)을 사용하므로 macOS 보안 정책에 따라 다운로드한 앱의 실행이 차단될 수 있습니다. 공증된 정식 배포판은 아직 제공하지 않으며, 개발 환경에서는 아래 방법으로 직접 빌드할 수 있습니다. 실제 실행 검증은 Apple Silicon에서 진행했습니다.

## 시작하기

1. **이미지 선택**을 누르거나 이미지 파일을 창에 끌어놓습니다.
2. 적용할 모니터를 선택합니다.
3. 전체 이미지의 확대·가로·세로 위치를 맞춥니다.
4. 모니터의 경계가 맞지 않으면 **모니터 보정**을 엽니다.
5. **화면에 적용**을 누릅니다. PNG만 필요한 경우 **PNG 내보내기**를 사용합니다.

| 단축키 | 동작 |
| --- | --- |
| `⌘O` | 이미지 선택 |
| `⌘Return` | 선택한 화면에 적용 |
| `⇧⌘E` | 화면별 PNG 내보내기 |
| `Esc` | 실제 화면의 정렬 패턴 종료 |

## macOS 배치와 실물 배치가 다를 때

미리보기 위의 배치 메뉴에서 기준을 선택합니다.

- **시스템 배치 따르기:** macOS 디스플레이 설정을 기준으로 배경을 계산합니다.
- **실제 배치 직접 설정:** 모니터 위치와 크기의 기준을 따로 저장합니다. macOS 배치를 바꾸거나 모니터를 다시 연결해도 저장한 수동 배치를 유지합니다.

수동 모드에 처음 들어가면 현재 배치에서 시작합니다. 미리보기의 화면을 실제 위치로 옮기고 크기를 맞추세요. **시스템 배치 불러오기**를 누르면 현재 macOS 배치로 수동 배치를 다시 시작할 수 있습니다. 시스템 모드의 보정값과 수동 모드의 보정값은 별도로 보관합니다.

이 기능은 macOS의 화면 배치, 해상도, 마우스 이동 경로를 바꾸지 않습니다. 배경화면에 사용할 영역만 조절합니다.

## 눈으로 크기와 경계 맞추기

1. **화면 내부를 드래그**해 위치를 옮깁니다.
2. 선택한 화면의 **모서리 핸들**을 끌어 크기를 바꿉니다. 반대쪽 모서리와 가로·세로 비율을 유지합니다.
3. **가장자리 맞춤**을 켜면 가까운 화면 경계에 맞춥니다. 이동할 때는 중심선에도 맞춥니다.
4. **미리보기 연결선**으로 격자·수평선·수직선·대각선의 연결을 확인합니다.
5. **화면에 정렬 패턴 표시**를 눌러 실제 모니터에 임시 패턴을 띄웁니다. 편집 창에서 조절하면서 선의 높이와 격자 간격이 이어지도록 맞춥니다.

정렬 패턴은 기존 배경화면을 변경하지 않습니다. **Esc**, 종료 버튼, **보정 완료**로 닫을 수 있습니다. 다른 앱으로 전환하거나 편집 창을 닫고 최소화하는 경우에도 종료합니다. 패턴을 닫은 뒤 **화면에 적용**을 눌러 선택한 이미지에 보정값을 반영합니다.

### 수치로 미세 조절

- **화면 상대 크기:** 25–400%. 작은 값일수록 해당 화면의 배경 무늬가 크게 보입니다.
- **좌우·상하 위치:** −10,000–10,000pt. 양수는 오른쪽·아래 방향입니다.
- 숫자 입력, 슬라이더, 미세 조절 버튼을 사용할 수 있습니다. 숫자는 Enter 또는 포커스 이동 시 반영합니다.
- **이 화면 초기화**는 선택한 화면을 초기화합니다. 수동 모드에서는 해당 화면을 현재 시스템 위치·크기로 되돌립니다.

보정값은 모니터 식별자별로 저장합니다. 전체 영역을 다시 계산하므로 한 화면의 조절에 따라 전체 이미지가 잘리는 범위도 달라질 수 있습니다. 실제 출력 파일의 픽셀 수는 모니터의 현재 출력 해상도를 유지합니다.

## 언어

왼쪽 위 **언어**에서 시스템 설정, 한국어, English를 선택합니다. 앱의 메뉴·설정·일반 안내 문구는 즉시 전환됩니다. macOS의 기본 파일 선택창과 일부 원본 OS 오류는 시스템 언어를 따를 수 있습니다.

## 저장과 복원

새 설치의 데이터는 `~/Library/Application Support/Waallpaper/`에 저장합니다.

- `source.png`: 선택한 이미지 사본
- `preferences.json`: 이미지 위치, 모니터 선택, 시스템·수동 배치, 언어
- `Wallpapers/`: 생성한 화면별 배경 이미지
- `backup.json`, `Backups/`: 기존 배경의 경로·표시 옵션과 가능한 경우 파일 사본

이전 개발 버전 **MoreWallpaper**의 데이터가 있으면 기존 저장 폴더를 계속 사용합니다. 이미 배경으로 적용된 파일 경로와 복원 기록을 유지하기 위한 호환 처리입니다.

**이전 배경 복원**은 처음 적용하기 전의 배경으로 되돌립니다. 다른 앱이 보호하는 폴더 등에서 원본 사본을 만들 수 없으면 경로와 표시 옵션만 보관하며 앱에 안내합니다. 원본이 이동·삭제되거나 접근이 제한되면 복원이 실패할 수 있습니다.

앱을 제거할 때는 먼저 이전 배경을 복원하세요. 현재 배경으로 쓰는 생성 파일을 삭제하면 해당 배경을 표시하지 못할 수 있습니다.

## 빌드

Swift 6 이상을 포함한 Xcode 또는 Command Line Tools, Python 3가 필요합니다. 외부 Swift 패키지 의존성은 없습니다.

```sh
git clone https://github.com/s1ckdark/waallpaper.git
cd waallpaper
swift test
./scripts/build-app.sh
open build/Waallpaper.app
```

```sh
# Apple Silicon + Intel
./scripts/build-app.sh --universal

# 실행 중인 개발 앱과 다른 경로에 생성
./scripts/build-app.sh --universal --output build/preview/Waallpaper.app

# ZIP, 체크섬, 서명 정보를 생성하고 압축 해제 후 검증
./scripts/package-release.sh
```

개발 중에는 `swift run Waallpaper` 또는 Xcode에서 `Package.swift`를 열어 실행할 수 있습니다. 배포 스크립트는 `build/releases/v<version>/`에 결과를 만들고, 기존 같은 버전의 결과를 덮어쓰지 않습니다.

## 현재 범위

- 정지 이미지용입니다. 동영상·동적 배경 재생은 지원하지 않습니다.
- 물리적 인치 크기와 베젤은 자동 측정하지 않으며 수동으로 보정합니다.
- 다른 Spaces와 잠금 화면까지 일괄 적용·복원하는 동작은 검증하지 않았습니다.
- 동적 배경의 재생 상태와 셔플 일정은 복원하지 않습니다.
- 이미지 디코딩·렌더링은 한 변 16,384px, 총 1억 픽셀 이하로 제한합니다.

검증 범위와 제한은 [QA 기록](docs/QA.md)을 참고하세요.
